## 1. Overview & Festival Heritage

**Pantheon** is the official annual science and technology festival of the **Birla Institute of Technology (BIT), Mesra, Ranchi**. It stands alongside *Bitotsav* (the cultural festival) as one of the premier technical conventions in Eastern India.

- **Host Institution:** Birla Institute of Technology, Mesra, Ranchi - 835215, Jharkhand, India.
- **Motto:** *"Innovation Meets Infinity"* / *"Tradition of Technology"*
- **Core Domain:** Robotics, Competitive Programming, Hackathons, Aerospace Engineering, CAD Design, Entrepreneurship, Game Development, and Cultural Night Highlights.

## 4. HackQuest '25 Flagship Hackathon

### Overview & Logistics
- **Duration:** 24-Hour Continuous Hackathon
- **Date & Time:** September 6, 2025 | Commencement at 10:00 AM, Coding starts at 12:00 PM
- **Venue:** Seminar Hall 2 and Seminar Hall 3, BIT Mesra
- **Team Size:** 3 to 5 Members per team (Individual participation prohibited)
- **Hostel & Hospitality:** Accommodation provided in institute hostels for outstation participants; dinner served at Institute Guest House (IGH). Stable high-speed Wi-Fi provided throughout.
- **Evaluation Structure:** 3 elimination rounds spaced 6–8 hours apart followed by a grand presentation pitch to industry experts.

### Problem Statements & Tracks

#### 1. **Searchable Memory for Teams (AI & Vector Search)**
- **Challenge:** Build an AI-powered unified knowledge layer integrating tools like Slack, Google Docs, Notion, GitHub, and Google Drive.
- **Technical Requirements:** Generate embeddings (OpenAI/Cohere), store in vector DB (Pinecone/Weaviate/Milvus), and build a chat interface to query cross-platform knowledge using natural language.

#### 2. **TrafficOps+ — Safer, Greener City Traffic Playbook (Computer Vision & Smart Cities)**
- **Challenge:** Computer-vision traffic signal system prioritizing emergency vehicles (ambulances/fire trucks) with green-wave routing while adjusting crosswalk timings for surge pedestrian traffic.
- **Technical Requirements:** YOLOv8 + OpenCV video processing, real-time dashboard displaying KPIs (emissions reduced, crosswalk safety index).

#### 3. **Digital Exhaust → Health Baseline (Privacy-Preserving Health Tech)**
- **Challenge:** Infer personal stress, focus, and fatigue baselines using device activity signals (typing dynamics, unlock frequency, screen time) without intrusive wearables.
- **Technical Requirements:** Anonymized signal processing, local ML inference, user-friendly wellness dashboard.

#### 4. **Tokenized Community Reputation System (Web3 & Decentralized Tech)**
- **Challenge:** dApp to reward open-source community contributions while preventing self-farming and spam using staking, slashing, and duplicate-wallet detection.
- **Technical Requirements:** Smart contracts (Solidity on Polygon/Ethereum), reputation scoring UI, automated penalty slashing.

#### 5. **SplitKaro Special: Expense Chatbot (Conversational Fintech)**
- **Challenge:** Conversational chatbot to add, split, and analyze group expenses through natural language ("I spent ₹500 on dinner with Rahul and Meera").

#### 6. **SplitKaro Special: Expense Automation (Automated Tracking)**
- **Challenge:** Redefine expense tracking by automatically reading SMS, digital receipts, and banking notifications with privacy-preserving classification.

#### 7. **Open Innovation Track**
- **Challenge:** Cross-domain hardware/software solutions addressing real-world societal problems using emerging technology stacks.

### FAQs
- **Prizes:** Cash Prizes + Certificates + Goodies + Mentorship Opportunities.
- **Team:** Managed by 20–25 Core Student Coordinators.

## 6. Pantheon '26 Architectural Vision

The repository is built with modern web architecture targeting **Cloudflare Workers** edge runtime:

- **Framework:** `vinext` (Vite + React Server Components for Next-style App Router)
- **Runtime:** Cloudflare Workers (`wrangler`)
- **Styling:** Tailwind CSS v4 + Glowing Sci-Fi Design System
- **Icons:** `lucide-react`
- **Data Models:** `app/data/pantheonData.ts`

### Build & Deployment Workflow:
```bash
# Start Dev Server
bun run dev

# Build for Cloudflare Workers
bun run build

# Deploy to Cloudflare Workers
bun run deploy
```
